# TaskFlow — Gerenciador de Tarefas Web

## Objetivo
Aplicação web para cadastrar, organizar e acompanhar tarefas pessoais em um quadro Kanban.

## Funcionalidades
- Dashboard com total de tarefas, pendentes, em andamento e concluídas.
- Cadastro de título, descrição, prioridade e prazo.
- Edição e exclusão de tarefas.
- Quadro Kanban com as colunas **A Fazer**, **Em Andamento** e **Concluídas**.
- Alteração do status das tarefas por botão.
- Pesquisa pelo título.
- Filtros por prioridade e status, que podem ser usados juntos.
- Armazenamento no `localStorage`, mantendo os dados após fechar ou atualizar a página.
- Layout responsivo para computador e celular.
- Aviso visual para tarefas atrasadas.

## Tecnologias
- HTML5
- CSS3
- JavaScript puro
- localStorage

Não utiliza frameworks, bibliotecas externas, APIs, backend ou banco de dados.

## Como executar
1. Baixe ou clone este repositório.
2. Abra a pasta `taskflow`.
3. Abra o arquivo `index.html` diretamente no navegador (Chrome, Edge ou Firefox).
4. Cadastre uma tarefa pelo botão **Nova tarefa**.

Os dados ficam salvos no navegador utilizado. Se abrir em outro navegador ou dispositivo, a lista será independente.

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: aparência e responsividade.
- `script.js`: cadastro, edição, exclusão, Kanban, pesquisa, filtros e localStorage.
